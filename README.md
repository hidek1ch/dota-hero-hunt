# Dota Hero Hunt --- Final Beta

Готовая сборка проекта для GitHub Pages.

## Публикация

1.  Загрузите `index.html`, `.nojekyll` и `README.md` в корень
    репозитория.
2.  В GitHub откройте **Settings → Pages**.
3.  В **Build and deployment** выберите **Deploy from a branch**.
4.  Выберите ветку `main` и папку `/ (root)`, затем **Save**.

Игра использует существующий Supabase backend для аккаунтов, профилей,
друзей и дуэлей. Секретных server/service-role ключей в клиентской
сборке нет.

### Важно

ZIP нужно сначала распаковать. Если загрузить сам ZIP как один файл в
репозиторий, GitHub Pages не распакует его автоматически.
